## How do you continue your demo save in the full game?

Use the full game's save screen and select the slot marked **[Demo]**. This is the transfer instruction given in the developer's [full-game launch announcement](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1846018067928563). No manual save-file path or copying step is specified there.

1. Open the full Steam game, App 3232690.
2. Go to the save screen.
3. Select the slot labeled **[Demo]** to continue the demo progress.

These steps follow the developer's statement. We have not claimed a firsthand transfer test on every operating system or older demo build.

## What changes when you move from the demo to the full game?

| Scope | Launch demo | Full game |
|---|---|---|
| Main story | First four chapters | Remaining chapters, an ending sequence and credits |
| Cafe level cap | 10 | 40 |
| Additional maids | Demo starts with Omu and Mina | Yuki, Jennie and Momo join as introduced by the main story |
| Additional systems | Limited demo scope | Inspections, festivals, expanded rooms and two stage systems |

The full-game maid level cap is 15. Read the [progression guide](/guides/progression/) for the distinction between Dance Stage work and Performance Stage filming.

## Why did an older demo save stop working?

The official September 29 demo update, version **1.16.22**, says the demo's save system was rewritten and earlier demo saves were incompatible with that updated demo. That historical reset is a separate event from the full-game launch's promise to carry demo saves forward.

Do not treat version 1.16.22 as the full game's release version. The same demo update also changed demo features and limits, so a June demo guide may describe a different build.

Source: the September 29 entry in the [official Steam news feed](https://api.steampowered.com/ISteamNews/GetNewsForApp/v2/?appid=3232690&count=50&maxlength=0&format=json), preserved in this project's source records.

## What if the Demo slot is missing?

The launch announcement does not provide a confirmed recovery method for a missing slot, an unsupported older demo build or a transfer between different computers. We therefore do not prescribe a guessed file path, a save-editor change or deletion of existing progress.

Check that you are opening the full Steam game and record which demo build produced the save. If the slot remains absent, contact the [developer's support community](https://discord.gg/dv2xNkvrpD), identifying the versions and what the save screen shows.

For a task that stops advancing after you have already loaded the save, use the [story troubleshooting checks](/guides/troubleshooting/) instead. To learn the cafe operations after transfer, see the [beginner walkthrough](/guides/walkthrough/).
