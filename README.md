## Content and evidence

Seven launch articles cover cafe operations, the 23 listed Steam achievements, progression, demo transfer, five maids and bond stories, the 20 DLC items, and sourced troubleshooting. Partial answers are labeled. Exact recipes, hidden achievement triggers, all main endings, a complete chapter route and numerical Maidchelin/bond thresholds remain deferred pending reliable evidence.

The keyword records, page matrix, source snapshots and evidence ledger are in `research/`. They distinguish historical user metrics, observed suggestions, community reports and unknown measurements. This is the Steam game; Roblox content and redemption codes are excluded.

## Local development

Use Node.js **>=22.13.0** and **pnpm 11.1.1** (the pinned package manager). The launch was validated with Node 24.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Before publication, run `pnpm check`, `pnpm lint`, `pnpm test`, `pnpm check-config`, `pnpm check-content`, `pnpm build`, `pnpm check-links` and `pnpm check-sitemap`. The sitemap check needs a running local preview, or `BASE_URL` set to the public site. Build output is `dist/`; Pagefind is generated by the native postbuild step.

Game identity is configured in `src/config/site.ts`, navigation in `src/config/navigation.ts`, English UI text in `src/locales/en.json`, and articles in `src/content/wiki/en/`. Ads, comments and analytics are disabled by default. Do not add credentials to this repository.

## Deployment

Cloudflare Pages project: `maid-cafe-simulator-wiki`, production branch: `main`. The initial release uses a direct upload. GitHub source hosting alone does not enable automatic Cloudflare deployment.

```sh
pnpm build
npm exec --yes --package=wrangler@4.149.0 -- wrangler pages deploy dist --project-name maid-cafe-simulator-wiki --branch main
```

The production origin is the actual Pages hostname. If a custom domain is connected later, update the site configuration and `SITE_URL`, rebuild, verify canonical/sitemap/redirect behavior, and submit the new sitemap. Keep the Google ownership verification file in `public/`.

## Tests and maintenance

Generic tests remain active. Fixed template data under `tests/fixtures/anvilwiki/` is test-only and is never deployed. Tests for the template's removed marketing website are preserved in `tests/upstream-only/` and explicitly excluded; see [launch notes](docs/launch-notes.md).

After launch, retain stable URLs and dates. Update only for a material game change, a factual correction, a proven search gap or a technical/indexing fault. Review on days 3, 7, 14 and 28; a review does not require editing or publishing more pages.
